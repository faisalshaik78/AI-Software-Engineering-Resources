## 🚀 Getting Started

If you are new to AI-assisted software development, try this learning path:

1. **Start with a coding assistant.** Use one tool to explain code, suggest changes, and help write tests.
2. **Try a repository-aware agent.** Give it a small, clearly scoped issue in a practice project.
3. **Review every change.** Read the diff, run the tests, and check the output before accepting modifications.
4. **Explore agent frameworks.** Once you understand basic tool use, experiment with a multi-agent framework.
5. **Learn the infrastructure.** Explore local model runners, API gateways, and isolated execution environments.
