# Contributing

Thank you for taking the time to improve **AI Software Engineering Resources**. Contributions that make this collection more useful, accurate, and easy to navigate are welcome.

## What you can contribute

- New AI coding assistants and developer tools
- Autonomous software engineering agents
- Multi-agent frameworks and orchestration projects
- Browser automation and agent infrastructure
- Benchmarks, tutorials, and useful learning resources
- Corrections to existing links or descriptions

## Before submitting

Please make sure that:

1. The project is relevant to AI-assisted software development or autonomous engineering.
2. You link to the official website, documentation, or source repository.
3. The description is short, clear, and neutral.
4. The project is publicly accessible and has enough information for readers to evaluate it.
5. You avoid unsupported claims about pricing, performance, company valuation, or popularity.

## How to contribute

1. Fork this repository.
2. Create a branch for your change:
   `git checkout -b add-tool-name`
3. Update the README or relevant resource file.
4. Check your Markdown formatting and test the links where possible.
5. Commit your changes with a clear message:
   `git commit -m "Add tool name to resources"`
6. Push your branch and open a Pull Request.

## Pull request checklist

- [ ] The resource is relevant to this repository.
- [ ] The link points to an official source.
- [ ] The description is accurate and written in your own words.
- [ ] No duplicate entry has been added.
- [ ] The README formatting is consistent.

Thank you for helping keep this resource list useful for the developer community.
